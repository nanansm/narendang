# Narendang — Biolink

Biolink resmi Narendang (pengganti linktr.ee/Narendang) untuk dua outlet:
Narendang Jl. Kalimantan dan Narendang Jl. Cisangkuy 58, Bandung.

Stack: HTML statis (folder `public/`) → Cloudflare Pages, tanpa build. Ubah isi di `tools/build.py` + `tools/style.css`, lalu `python3 tools/build.py`. Dibuat oleh Mote Kreatif.
Rencana desain: `docs/rencana-desain.md`.
